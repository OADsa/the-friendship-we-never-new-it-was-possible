# The friendship we never new it was possible.

A pink, early-2000s desktop-inspired friendship page with floating balloon hearts, draggable windows, hidden notes, and small interactive surprises.

## Launch on Vercel

Import the repository in Vercel and keep the default settings. This is a static site, so no build command or environment variables are needed.

## Preview locally

Open `index.html` directly in a browser, or serve this folder with any local static server.
